.) An annotation is metadata that gives details about the program and does not form part of the program.
Annotations have advantages as:

Input for the compiler -The compiler can use annotations to detect errors or to suppress warnings.

Deployment-time and Compile-time processing - Software tools can use annotation data for code generation, XML files, etc. 

Run-time processing - These annotations are available to be checked at run-time

For classes, variables, methods, parameters, and packages annotations can be used.

Annotations are written starting with a' @' symbol, followed by the name of the annotation and its elements, if any.
They can be of the following types:

Marker (without any element)

Single-valued (with a single element)

Multivalued (with multiple elements)

The @Deprecated annotation is a marker annotation and can be used to mark a class, a method or a field as deprecated. It means that it's no longer used.

One very important point about chars in Java not covered in the String code file :-
In Java, any arithmetic involving byte, short, or char is automatically promoted to int !
For example,
char c = 'A';
System.out.println(c+1); // output is 66 , not 'B'
Another point is that Java makes an exception for compile-time constants. So,
char c = 65; //OK
byte b = 100 //OK
but...
int x = 65;
char c = x; // Error !!
Even though x happens to be 65, its an variable, so the compiler can't apply the special rule for constant expressions !!
Java was designed to avoid accidental data loss from narrowing conversions.So, it does not allow an implicit narrowing conversion from int to char for the result of an arithmetic expression. Hence, Explicit type casting is needed to convert an int result of an arithmetic expression int its ASCII / UNICODE corresponding character.  
Hence,
char c = 'a' + 4; // Error !!
char c = (char)('a' + 4);  //  e , as wanted.

Another extremely important thing about Strings in Java:-
let String s be a String of length n. Now , consider the code below:
String temp = "";
for(int i=0; i<n; i++){
   temp += s.charAt(i);
}
return temp;
The time complexity of above code is O(n^2) ! Yes, its O(n^2) !!!
To achieve what you are trying to do above, or in general whenever you have to create a new string-like that you will make a lot of changes to like appending 
and deleting characters, use StringBuilder , for which .append() works in O(1).
So, rewriting the above code to achieve what we actually wanted to do:
StringBuilder temp = new StringBuilder("");
for(int i=0; i<n; i++){
  temp.append(s.charAt(i)) ;
}
return temp.toString() ;
Now, its the expected O(n) time complexity.
